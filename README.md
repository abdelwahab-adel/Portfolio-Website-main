# 📖 Overview

This portfolio website was designed and developed to represent my professional identity as a **Full-Stack Developer**. It highlights my technical skills, featured projects, work experience, education, certifications, and contact information through a modern and interactive interface.

The project focuses on delivering an exceptional user experience with clean architecture, responsive layouts, smooth animations, accessibility, and SEO optimization while using **pure HTML, CSS, and JavaScript without any frameworks**.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/abdelwahab-adel/Portfolio.git
```

Navigate to the project folder

```bash
cd Portfolio
```

Open the project

```bash
Open index.html in your browser
```

Or run using VS Code Live Server.
